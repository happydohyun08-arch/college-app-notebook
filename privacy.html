한국어

1. 내 자료는 내 브라우저에만 저장돼요

성적, 활동, 에세이, 지원 목록은 이 기기의 브라우저 저장소(localStorage)에만 있어요. 운영자 서버에는 저장하지 않아요. 운영자는 이용자 자료를 갖고 있지 않아 복구해 드릴 수도 없어요.

2. 외부로 나가는 경우: AI 평가

'AI 평가' 또는 'AI 순서 추천'을 누르고 매번 동의했을 때만, 그때 보낸 글(에세이·질문·학교 이름, 또는 활동·수상 목록과 전공)이 평가 서버(Cloudflare Workers)를 거쳐 Anthropic(Claude를 만든 회사)의 API로 전달돼요. 평가 서버는 그 내용을 저장하거나 기록하지 않고, 결과만 돌려줘요. Anthropic의 처리 방식은 Anthropic 개인정보 처리방침을 따라요. 보내기 전에 이름·연락처·학교 같은 개인정보는 지워 주세요.

3. Google 로그인 (AI 기능용)

AI 기능은 Google 로그인이 필요해요. 로그인하면 Google이 발급한 로그인 토큰(ID 토큰)을 AI 요청과 함께 평가 서버로 보내요.

  • 쓰는 것: 평가 서버는 토큰이 진짜인지(서명·발급자·대상·만료) 확인한 뒤 Google 계정 식별자(계정 번호, sub) 하나만 써요.
  • 저장하는 것: 하루 사용 횟수(계정당 하루 10회)를 세려고 계정 식별자와 IP 주소에 날짜를 붙여 알아볼 수 없게 바꾼 값(SHA-256 해시)과 횟수만 저장해요.
  • 보관 기간: 이 해시 값은 이틀(48시간) 뒤 자동으로 삭제돼요.
  • 쓰지 않는 것: AI 요청에서는 토큰에 이메일·이름이 들어 있더라도 평가 서버는 읽지도 저장하지도 않아요 (이메일은 5번 카운슬러 공유에서만 써요). 계정 식별자는 Anthropic으로 보내지 않아요.
  • 로그인 토큰은 열려 있는 페이지의 메모리에만 있고, 페이지를 새로 고치면 사라져요.

4. Google 드라이브 동기화 (선택)

Google로 로그인하면 내 자료를 내 Google 드라이브에서 불러오고, 고칠 때마다 다시 저장해요. 그래서 어느 기기에서 로그인해도 같은 자료가 보여요. 자료는 운영자 서버에 저장하지 않아요. 이때 요청하는 권한은 https://www.googleapis.com/auth/drive.appdata 하나뿐이에요. (5번 카운슬러 공유를 쓸 때만 drive.file 권한을 추가로 요청해요.)

  • 접근 범위: 내 드라이브의 앱 전용 숨김 폴더(appDataFolder)만 볼 수 있어요. 드라이브의 다른 파일은 보거나 읽거나 바꿀 수 없어요.
  • 하는 일: 그 폴더에 college-app-backup.json 백업 파일 하나를 둬요. 로그인하면 그 파일을 읽어요. 이 기기가 비어 있으면 드라이브 자료를 불러오고, 드라이브가 비어 있으면 이 기기 자료를 올려요. 둘 다 있고 내용이 다르면 묻지 않고 덮어쓰지 않아요: 양쪽의 저장 시각과 개수를 보여 주고 내가 고르게 해요. 연결된 동안은 자동 동기화가 켜져서 고칠 때마다(약 4초 묶어서) 같은 파일에 저장해요. 다른 Google 계정으로 로그인하면 자료를 섞지 않고 그 계정 자료로 바꿀지 따로 둘지 물어요. '드라이브에서 불러오기'·'드라이브에 저장'으로 직접 할 수도 있어요.
  • 전달: 백업은 브라우저에서 Google로 바로 가요. 운영자 서버를 거치지 않고, 운영자는 볼 수 없어요. 드라이브 데이터를 Anthropic이나 다른 곳으로 자동으로 보내지 않아요. 불러온 자료는 1번처럼 내 브라우저에만 있고, 내가 'AI 평가'를 눌러 동의한 글만 2번처럼 전달돼요.
  • 브라우저에 남는 것: 로그인 토큰과 드라이브 접근 토큰은 페이지 메모리에만 있고(약 1시간 유효) 저장하지 않아요. 브라우저에는 '로그인했었음' 표시, 자동 동기화 켜짐 여부, 마지막 동기화 시각, 이 기기 자료를 마지막으로 맞춘 Google 계정 번호(sub, 이메일 아님)만 저장해요. 드라이브가 로그인한 계정과 같은 계정인지 확인하려고 두 이메일을 페이지 안에서 비교하지만 저장하지 않아요. 다음에 열면 Google의 자동 로그인으로 다시 연결해요. 브라우저가 Google 창을 막으면 'Drive 연결'을 한 번 누르면 돼요.
  • 삭제와 연결 해제: 위쪽의 '로그아웃'은 토큰을 지우고 동기화를 멈추며, 공용 컴퓨터라면 이 기기의 자료도 지울 수 있게 해요(드라이브 백업은 남아요). '백업' 화면의 '구글 연결 끊기'를 누르면 접근 권한을 취소해요. 드라이브 백업을 지우려면 Google 드라이브 → 설정 → 앱 관리에서 이 앱의 '숨겨진 앱 데이터 삭제'를 누르세요. Google 계정 권한 페이지에서도 언제든 접근을 취소할 수 있어요.

5. 카운슬러 공유 (선택)

카운슬러(Google로 로그인한 누구나)가 '카운슬러' 탭에서 클래스를 만들면 6자리 코드가 나와요. 학생이 코드를 넣거나 이메일 초대를 받아 들어갈 때, 무엇이 누구에게 공유되는지 보여 주는 동의 화면에서 동의해야만 공유가 시작돼요.

  • 공유되는 것: 지원 학교 목록(학교·전형·마감일·상태), 준비 체크리스트, 에세이(제목·학교·질문·본문·완료 표시·단어 수), AI 총점과 항목별 점수. 성적·시험 점수·활동·수상·AI 설명 글은 공유하지 않아요.
  • 어디에 있나: 이 내용의 사본이 학생 본인 Google 드라이브에 파일 하나(클래스마다)로 만들어지고, 그 카운슬러의 이메일에만 읽기 전용으로 공유돼요. 학생이 고칠 때마다(드라이브 동기화 때) 사본도 바뀌어요. 카운슬러 브라우저는 그 파일을 Google에서 직접 읽고, 운영자 서버를 거치지 않아요.
  • 추가 권한: 이 기능을 쓸 때만 https://www.googleapis.com/auth/drive.file 권한을 요청해요. 이 권한으로는 이 앱이 만든 파일과 이용자가 직접 고른 파일만 다룰 수 있고, 드라이브의 다른 파일은 볼 수 없어요. 카운슬러는 처음 한 번 Google 파일 선택 창(Picker)에서 공유받은 학생 파일을 골라 읽기를 허락해요.
  • 운영자 서버에 저장하는 것: 클래스 코드와 이름, 카운슬러의 Google 계정 번호(sub)와 이메일, 학생의 Google 계정 번호와 이메일, 공유 파일 번호(Drive file id), 초대한 이메일, 가입 시각. 학생 자료나 에세이는 저장하지 않아요. 틀린 코드 입력 횟수를 세려고 계정 번호의 해시를 이틀 동안 저장해요.
  • 나가기: 학생은 언제든 '나가기'를 누를 수 있어요. 공유 파일을 지워 카운슬러의 접근이 바로 끝나고, 서버의 멤버십 기록도 지워요. 드라이브에서 그 파일을 직접 지워도 공유가 끝나요.
  • 카운슬러의 의무: 카운슬러는 학생 자료를 그 학생의 진학 지도에만 쓰고 다른 사람에게 넘기면 안 돼요.

9. 변경과 문의

방침이 바뀌면 이 페이지를 고치고, 서비스에서 다음 방문 때 다시 동의를 받아요. 개인정보 문의: dlehgus080310@gmail.com

English

1. Your data is stored only in your browser

Your scores, activities, essays and college list live only in this device's browser storage (localStorage). The operator's server never stores them. The operator does not hold your data and cannot restore it.

2. When data leaves your browser: AI feedback

Only when you press 'AI feedback' or 'AI order' and agree each time, the content you send (the essay, prompt and college name, or your activity and honors list with your major) goes through the feedback server (Cloudflare Workers) to the Anthropic API (Anthropic makes Claude). The server does not store or log it; it only returns the result. Anthropic handles it under the Anthropic privacy policy. Remove personal details such as your name, contact details or school before sending.

3. Google sign-in (for AI features)

AI features need a Google sign-in. When you sign in, the sign-in token Google issues (an ID token) is sent to the feedback server with each AI request.

  • What we use: the server checks that the token is genuine (signature, issuer, audience, expiry) and then uses only your Google account identifier (account number, sub).
  • What we store: to count daily use (10 per account per day), it stores only unreadable SHA-256 hashes of your account identifier and IP address, each combined with the date, plus the count.
  • Retention: these hashes are deleted automatically after two days (48 hours).
  • What we do not use: for AI requests, even if the token contains your email or name, the server neither reads nor stores them (email is used only for counselor sharing, section 5). Your account identifier is never sent to Anthropic.
  • The sign-in token stays only in the open page's memory and is gone when you reload.

4. Google Drive sync (optional)

When you sign in with Google, your data loads from your own Google Drive and is saved back on every change, so the same data appears on any device where you sign in. Your data is never stored on the operator's server. The only permission requested is https://www.googleapis.com/auth/drive.appdata (counselor sharing, section 5, additionally asks for drive.file only when used).

  • Access: only the hidden app-only folder in your Drive (appDataFolder). The site cannot see, read or change any other file in your Drive.
  • What it does: keeps one backup file, college-app-backup.json, in that folder and reads it when you sign in. If this device is empty, it loads the Drive data; if Drive is empty, it uploads this device's data. If both have data and they differ, nothing is overwritten silently: you see the last-saved time and item counts for each and choose. While connected, auto-sync is on and saves to the same file on every change (batched about 4 seconds). If a different Google account signs in, the data is not mixed: you choose whether to switch to that account's data or keep it separate. You can also use 'Load from Drive' and 'Save to Drive' by hand.
  • Sharing: the backup goes straight from your browser to Google. It never passes through the operator's server, and the operator cannot see it. Drive data is never sent automatically to Anthropic or anywhere else. Loaded data stays only in your browser (section 1); only text you choose to send with 'AI feedback' and agree to is shared (section 2).
  • What stays in the browser: the sign-in token and the Drive access token are kept only in page memory (valid about one hour) and are not saved. The browser stores only a 'was signed in' flag, whether auto-sync is on, the time of the last sync, and the Google account number (sub, not your email) this device's data was last synced with. To make sure Drive belongs to the account you signed in with, the page compares the two email addresses in memory; neither is saved. Next time you open the site, Google's automatic sign-in reconnects you; if the browser blocks the Google window, press 'Connect Drive' once.
  • Deletion and disconnect: 'Sign out' at the top clears the tokens, stops sync and, for shared computers, offers to remove your data from this device (the Drive backup stays). Press 'Disconnect Google' on the Backup screen to revoke access. To delete the Drive backup, open Google Drive → Settings → Manage apps and choose 'Delete hidden app data' for this app. You can also revoke access at any time on your Google Account permissions page.

5. Counselor sharing (optional)

A counselor (anyone signed in with Google) can create a class on the 'Counselor' tab and gets a 6-character code. When a student enters the code or accepts an email invite, sharing starts only after the student agrees on a consent screen that shows what is shared and with whom.

  • What is shared: the school list (school, round, deadline, status), the progress checklist, essays (title, college, prompt, full text, done flag, word count), and the AI total and per-criterion scores. Grades, test scores, activities, honors and AI feedback text are not shared.
  • Where it lives: a copy is saved as one file per class in the student's own Google Drive and shared read-only with that counselor's email only. It updates whenever the student edits (on Drive sync). The counselor's browser reads the file directly from Google; it never passes through the operator's server.
  • Extra permission: only when this feature is used, the site asks for https://www.googleapis.com/auth/drive.file. It covers only files this app created and files the user picks; it cannot see any other file in Drive. The first time, the counselor picks the shared student files in Google's file picker to allow reading them.
  • What the operator's server stores: the class code and name, the counselor's Google account number (sub) and email, each student's Google account number and email, the shared file id, invited emails, and join time. No student data or essays. To limit wrong-code guesses it keeps a hash of the account number for two days.
  • Leaving: students can press 'Leave' at any time. This deletes the shared file, so the counselor's access ends at once, and removes the membership record. Deleting the file in Drive also ends sharing.
  • Counselor duties: counselors may use student data only to advise that student and must not pass it on.

6. Google API Services User Data Policy (Limited Use)

College App Manager's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only for the features above (verifying sign-in and counting uses, backing up to your own Drive). It is not sold, not used for advertising, not used to train AI models, and not read by humans (except with your request, for security, or as required by law).

7. Deleting your data

Use 'Delete all data' on the Backup screen or clear your browser's site data to erase data on this device. Delete the Drive backup as described in section 4. Usage-count hashes on the server are deleted automatically after two days.

8. Age
